# 第1章 集合 关系 运算 结构

## 1.1 集合 子集 幂集 直积

**集合：** 是指有一些确定的对象汇集成的整体
- 用大写字母 A, B, X, Y 等表示集合
- 用小写字母 a, b, x, y 等表示集合的元素

**特定的集合表示：**
- N: 自然数集
- Z: 整数集
- Q: 有理数集
- R: 实数集
- C: 复数集
- $\emptyset$: 空集

**集合的表示方式：**
- 穷举法：列出集合中全部元素，如 $A = \{\sqrt{2}, -\sqrt{2}\}$
- 描述法：用集合中全部元素具有的特性来表述集合，如 $A = \{x | x^2-2=0, x\in R\}$

**集合的分类**
- 有限集：含有限个元素的集合
- 无限集：含无限个元素的集合

**相等 子集 幂集**
- 相等：设 A, B 是两个集合，如果A, B含的元素全相同，就说A, B相等
- 子集：如果对于任意的 $a\in A$， 均有 $b\in B$， 则称A是B的子集$A\subset B$
- 幂集：非空集合A的所有子集组成的集合称为A的幂集，记为 $P(A)$ 或 $2^A$

**笛卡尔积**
设 A, B 是两个非空集，我们把集合 $A \times B = \{(a,b)|a\in A,b\in B\}$

**交集 并集 余集（差集）**
- 交集：$A\cap B =\{x|x\in A\ 且\ x\in B\}$
- 并集：$A\cup B =\{x|x\in A\ 或\ x\in B\}$
- 余集：$A \backslash B (C_AB, A-B)= \{x|x\in A\ 但\ x\not \in B\}$

## 1.2 二元关系及其性质

**二元关系**： 设 X 是一个集合，R 是涉及两个元素的一个规则，如果对于 X 中的任两个元素 a, b 均可确定它们是适合 R (记为$aRb$)或不适合 R (记为$a\bar Rb$)，就称R是集X中的一个二元关系

**性质**
- 自反：对任意的$a\in X$, 均有 $aRa$，则称R是自反的
- 对称：对任意的$a, b\in X$, 若有 $aRb$ 就有 $bRa$，则称R是对称的
- 反对称：对任意的$a, b\in X$, 若由 $aRb$ 和 $bRa$ 可以推出 $a=b$ ，则称R是反对称的
- 传递：对任意的$a, b, c\in X$, 若由 $aRb$ 和 $bRc$, 就有 $aRc$， 则称R是传递的

## 1.3 等价关系 等价类 商集

**等价关系 等价类**

- *等价关系*：如果 R 是自反、对称和传递的，那么集合X 中的这个二元关系 R 称为等价关系
- *等价类*：设 R 是集 X 中的一个等价关系，$a, b\in X$, 如果 $aRb$, 则称a, b关于R是等价的，并把所有与a等价的元素集合 $\bar a = \{x|xRa, x\in X\}$ 称为 a 关于 R的等价类。
- **定理：** 设 R 是集 X 中的一个等价关系，$a, b\in X$, 则 $\bar a = \bar b$当且仅当 $aRb$
- **定理：** 若 R 是集 X 中的一个等价关系， 则 X 中存在关于R的一族互不相交的等价类$\{\bar{a_i}: a_i\in X,i\in I\}$

**商集**

以集 X 的等价关系 R 来划分的所有等价类作为元素所组成的集合，称为X关于R的商集， 记为 $X \backslash R$
例如：
- 整数集 Z 关于模 n 同余关系R的商集 $Z\backslash R =\{\bar 0, \bar 1,\bar 2,..., \bar{n-1}\}$ 

## 1.5 运算与映射

**运算**

设 X, Y, Z 都是非空集，所谓定义在 X, Y 上取值于Z的二元运算 "$\circ$" 是一个法则，它使任意的 $x\in X$ 和 $y\in Y$ 都有唯一的 $z\in Z$ 与之对应，则记为 $x\circ y=z$，如果$X=Y=Z$，则称这个二元运算为 X 上的一个代数运算，或者说是 X 上的封闭的二元运算

**映射**

设X, Y 是非空集，定义在 X 上取值于 Y 的一元运算 $\sigma$ 是一个法则，它使得 X 中每个元素 $\alpha$ 都有 Y 中唯一确定的元素 $\beta$ 与之对应。 这个一元运算 $\sigma$ 也称为集合 X 到 Y的一个映射， 记为：
$$ \sigma: X\rightarrow Y$$
并称 $\beta$ 为 $\alpha$ 在 $\alpha$下的像，$\alpha$ 为 $\beta$ 在 $\alpha$ 下的一个原像，记作
$$ \sigma : \alpha \mapsto \beta$$
