## Ch1 测量与量纲 {#ch1}

### 核心概念

- **SI 基本单位**：长度 m，质量 kg，时间 s，温度 K，电流 A，物质的量 mol，发光强度 cd
- **量纲分析**：物理量的量纲必须自洽，常用于验证公式
  - $[x]=L$，$[v]=LT^{-1}$，$[a]=LT^{-2}$，$[F]=MLT^{-2}$

### 常考题型

| 题型 | 解题思路 |
|------|----------|
| 推导某物理量的 SI 单位 | 代入已知公式，逐步化简单位 |
| 利用体积/面积计算质量 | 先求几何量，再乘密度 $m=\rho V$ |
| 有效数字处理 | 结果有效数字与输入数据对齐 |

**典型例题思路（砂粒总面积等于立方体面积）**：
$$N=\frac{6L^2}{4\pi r^2},\quad V_{total}=N\cdot\frac{4}{3}\pi r^3=2L^2r,\quad m=\rho\cdot 2L^2r$$

## Ch2 运动学：向量与一维运动 {#ch2}

### 核心公式

**向量运算**
$$\vec a\cdot\vec b = a_xb_x+a_yb_y+a_zb_z$$
$$\vec a\times\vec b = (a_yb_z-a_zb_y)\hat i+(a_zb_x-a_xb_z)\hat j+(a_xb_y-a_yb_x)\hat k$$

**一维匀变速运动**
$$v=v_0+at,\quad x=x_0+v_0t+\tfrac{1}{2}at^2,\quad v^2=v_0^2+2a\Delta x$$

**瞬时速度与加速度**
$$v=\frac{dx}{dt},\quad a=\frac{dv}{dt}=\frac{d^2x}{dt^2}$$

### 常考题型

| 题型 | 关键步骤 |
|------|----------|
| 变加速 $a(t)$ → 求速度和位移 | 积分：$v=\int a\,dt$，$x=\int v\,dt$ |
| 向量的大小与方向 | $|\vec a|=\sqrt{a_x^2+a_y^2}$，$\theta=\arctan(a_y/a_x)$ |
| 球竖直抛出求飞行时间 | $h=v_0t-\frac{1}{2}gt^2$，令 $h=0$ 解 $t$ |

## Ch3 力与牛顿定律 {#ch3}

### 核心定律

$$\sum\vec F=m\vec a \quad\text{（分量形式分别列方程）}$$

**重力**：$\vec F=mg$（近地面），**万有引力**：$F=G\dfrac{m_1m_2}{r^2}$

**弹力（胡克定律）**：$\vec F=-k\vec x$

**摩擦力**
$$\text{静：}F_s\leq\mu_s N;\quad\text{动：}F_k=\mu_k N$$

**斜面上的支持力**：$N=mg\cos\theta$

### 常考题型

| 题型 | 解题策略 |
|------|----------|
| 串联多物体系统求加速度和张力 | 整体法求 $a$，隔离法求各接触力 |
| 空气阻力 $D=bv$ 或 $D=bv^2$ 求终端速度 | 令 $ma=mg-D=0$，解出 $v_T$ |
| 斜面上物体运动 | 沿斜面/垂直斜面分解力，分别列方程 |

**串联系统关键技巧**：用整体法求合加速度，再用隔离法求各段绳的张力，从后向前逐段分析。

## Ch4 二维与三维运动 {#ch4}

### 抛体运动

$$\begin{cases}
x=v_0\cos\theta\cdot t\\
y=v_0\sin\theta\cdot t-\dfrac{1}{2}gt^2
\end{cases}$$

**轨迹方程**（消去 $t$）：
$$y=x\tan\theta-\frac{gx^2}{2v_0^2\cos^2\theta}$$

**水平射程（$\theta=45°$ 时最大）**：
$$R=\frac{v_0^2\sin 2\theta}{g},\quad R_{max}=\frac{v_0^2}{g}$$

### 匀速圆周运动

| 物理量 | 公式 |
|--------|------|
| 向心加速度 | $a_c=\dfrac{v^2}{r}=r\omega^2$ |
| 向心力 | $F_c=m\dfrac{v^2}{r}$ |
| 周期 | $T=\dfrac{2\pi r}{v}=\dfrac{2\pi}{\omega}$ |
| 切向加速度（变速圆周） | $a_t=\dfrac{dv}{dt}$ |

**圆锥摆（水平圆周运动）**：
$$T\cos\theta=mg,\quad T\sin\theta=m\frac{v^2}{r} \implies v=\sqrt{rg\tan\theta}$$

### 常考题型

| 题型 | 关键 |
|------|------|
| 抛体运动轨迹/射程 | 先求时间，再代入坐标公式 |
| 圆周运动受力分析 | 合力指向圆心 = 向心力，$\sum F_r=\frac{mv^2}{r}$ |
| 摆在最低/最高点的速度和张力 | 能量守恒求速度，再做受力分析 |

## Ch5 牛顿定律的应用（非惯性系） {#ch5}

### 核心概念

**惯性力**：非惯性系中引入的虚拟力，$\vec F_p=-m\vec a_{frame}$（方向与参考系加速度相反）

**非惯性系牛顿第二定律**：
$$\sum\vec F_0+\vec F_p=m\vec a'$$

**旋转非惯性系**

| 伪力 | 公式 | 方向 |
|------|------|------|
| 离心力 | $F=m\omega^2r$ | 背离圆心 |
| 科里奥利力 | $\vec F_c=2m\vec v'\times\vec\omega$ | 垂直于相对速度 |

### 常考题型

- **滑轮组（Atwood机变形）**：把动滑轮子系统视为非惯性系，内部施加惯性力，再列方程联立求解
- **漏斗内小块平衡**：沿径向和竖直方向列方程，求极值角速度

## Ch6 动量与碰撞 {#ch6}

### 核心公式

$$\vec p=m\vec v,\quad\vec J=\int\vec F\,dt=\Delta\vec p$$

**动量守恒条件**：合外力为零（各分量独立守恒）

### 三种碰撞

| 类型 | 守恒量 | 特征 |
|------|--------|------|
| 弹性碰撞 | 动量 + 动能 | 两方程求两末速 |
| 非弹性碰撞 | 动量 | 动能损失 |
| 完全非弹性碰撞 | 动量 | 碰后共速 $v_f=\frac{m_1v_{1i}+m_2v_{2i}}{m_1+m_2}$ |

**弹性碰撞解析结果（1D）**：
$$v_{1f}=\frac{m_1-m_2}{m_1+m_2}v_{1i},\quad v_{2f}=\frac{2m_1}{m_1+m_2}v_{1i}$$

**质心参考系（CM frame）技巧**：
$$v_{cm}=\frac{m_1v_{1i}+m_2v_{2i}}{m_1+m_2},\quad\text{弹性碰撞在CM系中速度各自反转}$$

### 常考题型

| 题型 | 策略 |
|------|------|
| 子弹穿过木块 | 动量守恒求末速，或逐段用能量法 |
| "弹弓效应"（飞船绕行星） | CM系中速度反转，再变换回Lab系 |
| 多次连环碰撞 | 逐次分析，每次用动量守恒 |
| 爆炸类题（枪炮后坐） | 系统水平动量守恒（水平合外力为零） |

## Ch7 质点系统与变质量运动 {#ch7}

### 质心计算

**离散系统**：$x_{cm}=\dfrac{\sum m_ix_i}{M}$

**连续体**：
$$x_{cm}=\frac{1}{M}\int x\,dm,\quad
\begin{cases}
dm=\lambda\,dl & \text{线分布}\\
dm=\sigma\,dA & \text{面分布}\\
dm=\rho\,dV & \text{体分布}
\end{cases}$$

**半圆板质心**（直径在x轴）：$y_{cm}=\dfrac{4R}{3\pi}$

### 火箭方程

$$v_f-v_i=u\ln\frac{M_i}{M_f}$$（$u$ 为喷气相对速度，无外力情况）

### 常考题型

| 题型 | 方法 |
|------|------|
| 不规则形状质心 | 对称性 + 积分（或加减法：大图形减挖去部分） |
| 火箭/炮弹动量 | 整体动量守恒；或用火箭方程 |
| 枪炮角度求炮弹速度 | 水平动量守恒 → 求反冲速度 → 用速度合成 |

## Ch8 转动运动学 {#ch8}

### 核心公式

| 物理量 | 公式 |
|--------|------|
| 角位移、角速度、角加速度 | $\omega=d\phi/dt$，$\alpha=d\omega/dt$ |
| 匀变角速度 | $\omega=\omega_0+\alpha t$，$\phi=\omega_0t+\frac{1}{2}\alpha t^2$，$\omega^2=\omega_0^2+2\alpha\phi$ |
| 线速度与角速度 | $v=r\omega$ |
| 切向加速度 | $a_t=r\alpha$ |
| 向心加速度 | $a_c=r\omega^2=v^2/r$ |

**⚠️ 注意**：形式与一维运动学完全类比，把 $x\to\phi$，$v\to\omega$，$a\to\alpha$，$F\to\tau$，$m\to I$ 即可。

### 常考题型

- 已知 $\theta(t)$ 求 $\omega(t)$ 和 $\alpha(t)$：对时间逐次求导
- 已知车轮停止时的转数求角加速度：用 $\omega^2=\omega_0^2+2\alpha\phi$

## Ch9 转动动力学 {#ch9}

### 力矩与转动方程

$$\vec\tau=\vec r\times\vec F,\quad|\tau|=rF\sin\theta$$
$$\sum\tau=I\alpha$$

### 常见刚体转动惯量

| 物体 | 转轴位置 | $I$ |
|------|----------|-----|
| 细杆（质量M，长L） | 过中点，垂直杆 | $\frac{1}{12}ML^2$ |
| 细杆 | 过一端，垂直杆 | $\frac{1}{3}ML^2$ |
| 细圆环（半径R） | 中心轴 | $MR^2$ |
| 实心圆盘（半径R） | 中心轴 | $\frac{1}{2}MR^2$ |
| 薄圆壳（半径R） | 直径 | $\frac{2}{3}MR^2$ |
| 实心球（半径R） | 直径 | $\frac{2}{5}MR^2$ |

**平行轴定理**：$I=I_{cm}+Md^2$（$d$ 为两轴间距）

**垂直轴定理（薄板）**：$I_z=I_x+I_y$

### 常考题型

| 题型 | 方法 |
|------|------|
| 非均匀细杆求质心/转动惯量 | 积分 $I=\int x^2\lambda(x)\,dx$ |
| 滑轮（有质量）连接悬挂物 | 平动方程 + 转动方程（注意两侧绳张力不等） |
| 复合滑轮求加速度 | $a_1=R_1\alpha$，$a_2=R_2\alpha$ 联立 |

**带质量滑轮 Atwood 机关键点**：
- 绳子两侧张力 $T_1\neq T_2$（正是这个差值提供力矩）
- 联立 $m_1g-T_1=m_1a$，$T_2-m_2g=m_2a$，$(T_1-T_2)R=I\alpha$，$a=R\alpha$

## Ch10 角动量 {#ch10}

### 核心公式

$$\vec L=\vec r\times\vec p=\vec r\times m\vec v,\quad|\vec L|=rmv\sin\theta$$

**角动量定理**：
$$\frac{d\vec L}{dt}=\vec\tau$$

**角动量守恒条件**：合外力矩为零（$\sum\vec\tau=0\Rightarrow\vec L=\text{const}$）

**刚体绕定轴的角动量**：$L_z=I\omega$

**角动量守恒在变转动惯量中的应用**：
$$I_1\omega_1=I_2\omega_2$$

### 典型问题

**纯滚动小球在圆弧轨道**（以接触点为参考轴）：
- $\tau_{mg}=mgr\cos\theta$，$I_{contact}=\frac{7}{5}mr^2$（平行轴定理）
- $\alpha=\frac{5g\cos\theta}{7r}$，$a_t=r\alpha=\frac{5g\cos\theta}{7}$

**冲量施加位置求初始角速度**：
- 线冲量：$J=mv_0$
- 角冲量：$J_{ang}=J\cdot h=I_{cm}\omega_0$（$h$ 为作用点到质心的力臂）

### 常考题型

| 题型 | 策略 |
|------|------|
| 花样滑冰/天体转动：收臂/展臂 | $I_1\omega_1=I_2\omega_2$，再求动能变化 |
| 卡车内圆盘滚动 | 非惯性系：施加惯性力，平动+转动联立 |
| 球棒/棒球受冲量 | 线冲量→初速，角冲量→初角速，再判断是否纯滚 |

## Ch11 功与动能 {#ch11}

### 核心公式

$$W=\int\vec F\cdot d\vec r=\int(F_x\,dx+F_y\,dy)$$

**动能定理**：$W_{net}=\Delta K=\frac{1}{2}mv_f^2-\frac{1}{2}mv_i^2$

**转动功与功率**：
$$W_{rot}=\int\tau_z\,d\theta,\quad P=\tau\omega$$

**转动动能**：$K_{rot}=\frac{1}{2}I\omega^2$

**刚体总动能（平动+转动）**：
$$K=\underbrace{\frac{1}{2}Mv_{cm}^2}_{\text{平动}} + \underbrace{\frac{1}{2}I_{cm}\omega^2}_{\text{转动}}$$

**纯滚动**：$v_{cm}=R\omega$（接触点静止，静摩擦力不做功，机械能守恒）

### 常考题型

| 题型 | 关键点 |
|------|--------|
| 圆柱/球在斜面无滑动滚下 | 机械能守恒（纯滚），$mgh=\frac{1}{2}mv^2+\frac{1}{2}I_{cm}\omega^2$ |
| 不同形状刚体滚下比速度 | $v_{cm}=\sqrt{\frac{2gh}{1+I_{cm}/(MR^2)}}$，$I$越大末速越小 |
| 求摩擦力在滚动中做功 | 纯滚时静摩擦力做功为零（质心处位移=0） |

## Ch12 势能 {#ch12}

### 核心概念

**保守力**：做功只与起终点有关，$\oint\vec F\cdot d\vec r=0$，例如重力、弹力、万有引力

$$W_{conservative}=-\Delta U,\quad F(x)=-\frac{dU}{dx}$$

**三维情形**：$\vec F=-\nabla U=\left(-\frac{\partial U}{\partial x},-\frac{\partial U}{\partial y},-\frac{\partial U}{\partial z}\right)$

### 常见势能

| 力 | 势能 |
|----|------|
| 重力 $mg$ | $U=mgh$ |
| 弹力 $-kx$ | $U=\frac{1}{2}kx^2$ |
| 万有引力 $-GMm/r^2$ | $U=-GMm/r$ |

### 机械能守恒

$$\Delta K+\Delta U=0 \iff E_k+U=\text{const}$$

**势能曲线**：$dU/dx=0$ 为平衡点；极小值→稳定平衡；极大值→不稳定平衡

### 常考题型

| 题型 | 方法 |
|------|------|
| 有弹簧系统选取系统边界 | 把弹簧纳入系统内，用机械能守恒；或把弹簧视为外力，用功能定理 |
| 由势能函数求力 | $F_x=-\partial U/\partial x$ 即可 |
| 平衡稳定性判断 | 画出或分析 $U(x)$ 的极值类型 |

## Ch13 能量守恒 {#ch13}

### 核心方程

$$\Delta K+\Delta U+\Delta E_{int}=W_{ext}$$

- 若只有保守力且无外力：$\Delta K+\Delta U=0$（机械能守恒）
- 含非保守力（摩擦）：$\Delta E_{int}>0$（内能增加），需从总量中减去摩擦耗散

**质心能量方程**：
$$\int\vec F_{ext}\cdot d\vec x_{cm}=\Delta K_{cm}$$（外力只改变质心动能）

**热力学第一定律**：$\Delta E_{int}=W_{ext}+Q$

### 常考题型

| 题型 | 关键 |
|------|------|
| 粗糙斜面上滑/下滑 | 单次摩擦耗散 $\Delta E_{int}=\mu Nd$；往返加倍 |
| 碰撞中内能增加 | $\Delta E_{int}=K_i-K_f$（动量守恒求末速后算） |
| 实心球纯滚进入圆环 | 机械能守恒 $mgh=\frac{7}{10}mv^2$，再做向心力分析 |
| 弹跳球能量损失 | $E_n=E_0\cdot r^n$（$r$ 为每次保留比例），解指数不等式 |

## 平动与转动对比总表 {#analogy}

| 物理量 | 平动 | 转动 |
|--------|------|------|
| 惯性 | 质量 $m$ | 转动惯量 $I=\int r^2\,dm$ |
| 运动量 | 线速度 $v$ | 角速度 $\omega$ |
| 运动变化量 | 加速度 $a$ | 角加速度 $\alpha$ |
| 动力学量 | 力 $F$ | 力矩 $\tau=r\times F$ |
| 动力学方程 | $F=ma$ | $\tau=I\alpha$ |
| 动量 | $p=mv$ | 角动量 $L=I\omega$，$\vec L=\vec r\times\vec p$ |
| 动量定理 | $J=\Delta p$ | $J_{ang}=\Delta L$ |
| 守恒条件 | $\sum F_{ext}=0$ | $\sum\tau_{ext}=0$ |
| 动能 | $K=\frac{1}{2}mv^2$ | $K=\frac{1}{2}I\omega^2$ |
| 功 | $W=\int F\,dx$ | $W=\int\tau\,d\theta$ |
| 功率 | $P=Fv$ | $P=\tau\omega$ |

## 常见题型与解题技巧 {#tips}

### 1. 受力分析通用流程

1. **明确研究对象**（单体 or 整体法）
2. **画受力图**：重力、支持力、张力、摩擦力、弹力
3. **建立坐标系**：通常沿运动方向为正方向（斜面取沿斜面方向）
4. **列方程**：$\sum F_x=ma_x$，$\sum F_y=ma_y$
5. **联立求解**，最后验证方向合理性

### 2. 能量法 vs. 牛顿法

| 方法 | 适用场景 |
|------|----------|
| 牛顿定律 | 需要知道某时刻的力、加速度、时间 |
| 动能定理/能量守恒 | 只关心初末状态的速度，不关心过程细节 |
| 动量守恒 | 系统碰撞、爆炸，合外力为零或时间极短 |
| 角动量守恒 | 合外力矩为零，旋转系统中的分析 |

### 3. 滚动问题三步法

1. 判断是否**纯滚动**（$v_{cm}=R\omega$，无滑动摩擦做功）
2. 用**机械能守恒**求速度：$mgh=\frac{1}{2}mv_{cm}^2+\frac{1}{2}I_{cm}\omega^2$
3. 转动惯量代入：圆盘 $\frac{1}{2}MR^2$，球 $\frac{2}{5}MR^2$，得到 $v_{cm}=\sqrt{\frac{2gh}{1+I/(MR^2)}}$

**结论**：质量分布越靠外（$I$ 越大），末速越小；球 > 圆柱 > 环

### 4. 碰撞题解题步骤

1. **判断碰撞类型**（弹性/非弹性/完全非弹性）
2. 写出**动量守恒方程**（矢量，可分量）
3. 若弹性：加上**动能守恒方程**
4. 若完全非弹性：碰后**共速**
5. 代入求解，验证动量方向正确

### 5. 转动惯量计算技巧

- **加减法**：复合形状 = 整体 – 挖去部分
- **平行轴定理**：$I=I_{cm}+Md^2$（知道质心处先算质心处）
- **积分法**：先写质量元 $dm$，选合适的积分变量（线/面/体密度）

### 6. 万有引力与势能题

- 空腔引力：**叠加原理**，完整球 – 挖去部分的球
- 环的轴向引力：$F_x=G\dfrac{Mmx}{(R^2+x^2)^{3/2}}$
- 在地球内部重力随半径**线性变化**（均匀球）：$g(r)=g_s\dfrac{r}{R}$

### 7. 非惯性系问题

- 加速电梯：效果等价于改变 $g$；向上加速 → $g_{eff}=g+a$
- 旋转参考系：引入**离心力**（背离轴）和**科里奥利力**（垂直速度）
- 解题时先在非惯性系中加上伪力，再用牛顿第二定律

$$\boxed{
\begin{aligned}
&\text{牛顿第二定律：}\sum\vec F=m\vec a\\
&\text{动量定理：}\vec J=\Delta\vec p\\

&\text{机械能守恒：}K+U=E=\text{const}\\
&\text{角动量定理：}\vec\tau=d\vec L/dt\\
&\text{转动方程：}\sum\tau=I\alpha\\
&\text{纯滚动：}v_{cm}=R\omega\\
&\text{弹性碰撞1D：}v_{1f}=\frac{m_1-m_2}{m_1+m_2}v_{1i}\\
&\text{火箭方程：}\Delta v=u\ln(M_i/M_f)\\
&\text{平行轴定理：}I=I_{cm}+Md^2\\
\end{aligned}
}$$
