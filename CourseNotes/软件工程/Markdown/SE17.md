# Chapter 17 WebApp Design

## Why Design WebApps?
WebApp 设计越早越重要，尤其是在内容多、功能多、业务影响大的场景里。

- content and function are complex
- scale is large
- business impact is high

## WebApp Quality
WebApp 质量不只看能不能跑，还要看多维属性。

- security
- availability
- scalability
- time to market
- accuracy and consistency
- response time and performance

## WebApp Design Goals
设计目标要能直接反映业务诉求。

- identity
- robustness
- navigability
- visual appeal
- compatibility

## WebApp Interface Design
界面设计要回答三个问题。

- Where am I?
- What can I do now?
- Where have I been / where am I going?

## Interface Design Principles
WebApp 界面要兼顾可预期性和效率。

- anticipation
- communication
- consistency
- controlled autonomy
- efficiency
- focus
- Fitt’s Law
- latency reduction
- learnability
- track state
- visible navigation

## Aesthetic Design
美观不是装饰，而是可读性和布局秩序的一部分。

- 少即是多
- 强调内容
- 左上到右下组织布局
- 分组要清晰
- 不要滥用滚动条

## Content Design
内容设计关注内容对象以及它们如何呈现。

- define content objects
- describe relationships among content objects
- support presentation and navigation
- keep content and implementation attributes分开考虑

## Architecture Design
WebApp 架构要同时支持内容、交互、导航和处理。

- content architecture
- MVC architecture
- architecture design runs in parallel with interface and content design

## Navigation Design
导航设计要先理解用户层级和用例。

- navigation semantic unit (NSU)
- ways of navigation (WoN)
- navigation node / link
- links, bars, tabs, site maps

## Component-Level Design
WebApp 组件负责具体处理任务。

- localized processing
- business-domain computation
- database access
- external system interfaces
