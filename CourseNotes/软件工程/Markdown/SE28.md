# Chapter 28 Formal Modeling and Verification

## Why Formal Methods?
形式化方法适合那些对正确性要求极高的系统。

- cleanroom software engineering
- formal methods
- specialized specification and verification
- goal is near bullet-proof software

## The Cleanroom Strategy
Cleanroom 的核心是“先规格，再证明，再少量统计测试”。

- increment planning
- requirements gathering
- box structure specification
- formal design
- correctness verification
- code generation, inspection, and verification
- statistical test planning and usage testing
- certification

## Functional Specification and Cleanroom Design
功能规格说明和设计细化要保持可证明的正确性。

- black box specification
- state box / clear box refinement
- sequence, conditional, loop refinement
- correctness questions guide the refinement

## Cleanroom Testing
Cleanroom 测试重点不是“多测”，而是“按使用概率测”。

- statistical usage testing
- create usage scenarios and probability distribution
- execute sampled tests
- record failure data and compute reliability

## Formal Methods and Formal Specification
形式化规格要解决自然语言规格中的歧义。

- consistency
- completeness
- lack of ambiguity
- use set theory and logic notation

## Formal Method Concepts
形式化语言通常会描述状态、操作和约束。

- data invariant
- state
- operation
- precondition
- postcondition
