# Chapter 18 MobileApp Design

## Mobile Development Considerations
移动应用的设计比传统 Web 更受平台和设备限制影响。

- 多硬件 / 多软件平台
- 多种开发框架和语言
- app store 规则不同
- 周期短、界面受限
- 相机 / 传感器交互复杂
- 电量、安全、隐私、存储都要考虑

## MobileApp Development Process
移动应用通常按更快的节奏推进。

- formulation
- planning
- analysis
- engineering
- implementation and testing
- user evaluation

## MobileApp Quality Checklist
设计前先检查关键质量维度。

- 是否能按用户偏好定制
- 是否能适配带宽和弱网
- 是否考虑电量和设备能力
- 是否兼顾屏幕尺寸和交互标准
- 是否满足可靠性、安全和隐私期望

## MobileApp UI Design Considerations
移动端 UI 要更聚焦、更克制。

- define brand signatures
- focus the portfolio
- identify core user stories
- optimize UI flows and elements
- define scaling rules
- create user performance dashboard

## MobileApp Design Mistakes
移动端常见错误往往是把桌面思路直接搬过来。

- kitchen sink
- inconsistency
- overdesigning
- lack of speed
- verbiage
- non-standard interaction
- help-and-FAQ-itis

## MobileApp Design Best Practices
好的移动端设计要贴合场景。

- identify the audience
- design for context of use
- use the platform as an advantage
- make advanced features discoverable
- keep labels clear and consistent
- long scrolling forms are often better than many screens

## Assessing Mobile Development Environments
开发环境本身也要评估。

- productivity features
- SDK integration
- post-compilation tools
- over-the-air support
- GUI builders
- docs and tutorials

## MobileApp Middleware
middleware 负责屏蔽移动环境差异。

- supports communication and coordination
- hides environment details
- helps context awareness

## Case: 智慧城管
案例展示移动应用如何把城市管理服务和市民参与结合起来。

- 提供便民服务和城市管理入口
- 支持拍照上报、记录查询、路线导航
- 典型场景体现了移动端的上下文感知和现场交互
