# Chapter 25 Testing Web Applications

## Quality Dimensions
WebApp 测试要覆盖内容、功能、结构、可用性、导航、性能、兼容性、互操作性和安全。

- content
- function
- structure
- usability
- navigability
- performance
- compatibility
- interoperability
- security

## The Testing Process
测试从内容和界面开始，再向功能、导航、配置和安全扩展。

- review content model
- review interface model
- review navigation model
- unit test functional components

## Content Testing
内容测试要抓语法、语义和结构问题。

- typos, grammar, punctuation
- factual accuracy and completeness
- organization and structure of content

## Database Testing
数据库测试要检查多层数据关系和访问逻辑。

- tests are defined for each layer
- focus on schema, data integrity, and access paths

## UI Testing and Interface Mechanisms
界面测试既看外观，也看机制。

- links
- forms
- client-side scripting
- dynamic HTML
- pop-up windows
- CGI / streaming / cookies

## Usability and Compatibility Testing
可用性和兼容性必须在真实环境中验证。

- test by user categories and usage scenarios
- instrument interaction during test
- define common client-side configurations
- use browser / platform matrices

## Navigation Testing
导航测试要把死链、错链、跳转和搜索都测到。

- navigation links
- redirects
- bookmarks
- frames and framesets
- site maps
- internal search engines

## Security, Performance, Load and Stress Testing
WebApp 的非功能测试很关键。

- security testing probes vulnerabilities
- performance testing checks response time and degradation
- load testing measures throughput under load
- stress testing checks behavior beyond capacity
