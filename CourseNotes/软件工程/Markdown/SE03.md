# Chapter 3 Software Process Structure

## 3.1 A Generic Process Model
软件过程可以理解成一组框架活动，再加上一组支撑性的 umbrella activities。

- framework activities describe major phases
- process flow explains how activities connect
- umbrella activities support quality and control across the whole process

## 3.4 Process Patterns
过程模式把常见的软件过程经验固定下来，便于复用。

- pattern name
- intent
- type
- initial context
- solution
- resulting context
- related patterns
- known uses/examples

## 3.5 Process Assessment
过程评估关注组织的软件过程成熟度和可改进点。

- SCAMPI
- SPICE (ISO/IEC 15504)
- CBA IPI
- ISO 9001 for Software

## Capability Maturity Model Integration
CMMI 用等级描述过程成熟度。

- Level 0: Incomplete
- Level 1: Performed
- Level 2: Managed
- Level 3: Defined
- Level 4: Quantitatively Managed
- Level 5: Optimizing
