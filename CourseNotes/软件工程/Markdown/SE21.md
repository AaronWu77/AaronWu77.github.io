# Chapter 21 Software Quality Assurance

## Comment on Quality
质量不是“最后检查一下”就能得到的，而是要从过程开始就做进去。

- quality is everyone’s concern
- quality management is a process issue
- quality has to be built in, not bolted on

## Elements of SQA
SQA 不是单点活动，而是一个体系。

- standards
- reviews and audits
- testing
- defect collection and analysis
- change management
- education
- vendor management
- security and safety
- risk management

## SQA Tasks
SQA 组要做的事情包括规划、检查、记录和报告。

- prepare the SQA plan
- review the software process description
- verify compliance with process and standards
- document deviations and track corrections
- report results to management

## SQA Goals
SQA 的目标是让质量目标可见、可度量、可管理。

- requirements quality
- design quality
- code quality
- quality control effectiveness

## Statistical SQA
统计型 SQA 关注缺陷数据和原因分析。

- collect defects
- classify defects
- trace defects to root causes
- use Pareto principle to find the vital few
- fix the process, not just the product

## Six Sigma for Software Engineering
Six Sigma 强调用数据驱动持续改进。

- define
- measure
- analyze
- improve
- control

## Software Reliability and Safety
可靠性和安全性是质量的重要组成部分。

- reliability is usually expressed with MTBF / MTTF / MTTR
- safety focuses on identifying hazards early
- hazards should be eliminated or controlled in design

## ISO 9001
ISO 9001 提供了质量保证体系的标准框架。

- management responsibility
- document and data control
- process control
- inspection and testing
- corrective and preventive action
- training and audits

质量工作要落到文档和记录上。

- quality assurance process

- checklist and score sheets

- process audit report
