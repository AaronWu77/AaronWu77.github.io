# Chapter 26 Testing Mobile Applications

## Mobile Testing Strategy Questions
移动测试必须先想清楚“在哪测、怎么测、测什么设备”。

- 是否需要完整原型后再测用户
- 用用户自己的设备还是提供测试设备
- 选哪些 device / user group
- lab testing 还是 remote testing

## Mobile Testing Guidelines
移动测试要尽量接近真实使用场景。

- understand network and device landscape
- test under uncontrolled real-world conditions
- choose the right automation tool
- test key hardware/platform combinations
- use actual devices for performance and compatibility

## Mobile App Testing Types
移动端测试要覆盖功能和环境两条线。

- unit / system / conceptual testing
- user experience testing
- stability testing
- connectivity testing
- performance testing
- compatibility testing
- security testing
- certification testing

## Automated Testing
自动化测试在移动端很有价值，但要先验证可行性。

- feasibility analysis
- proof of concept
- best-practice framework
- customize tools
- reuse test scripts

## Stress Test Cases
压力测试要把极端情况提前想好。

- multiple apps on one device
- malware or virus scenarios
- large transaction volumes
- large on-device data stores

## Mobile Usability Elements
移动可用性要关注交互和上下文。

- functionality
- information architecture
- screen design
- user input mechanisms
- context awareness
- feedback and help

## Specialized Usability Tests
特殊交互也要专门测。

- gestures
- voice input and recognition
- virtual keyboard input
- alerts and errors

## Testing the “现场抓拍” Scenario
案例测试要直接围绕真实业务功能展开。

- camera and microphone invocation
- upload failure handling
- confirm-submit behavior
- network error warning
- record creation in query module
- cross-device compatibility

## Mobile Testing Tools
工具应支持真机、记录、分析和远程调试。

- page compliance checkers
- device and browser emulators
- key logging / playback
- network monitors
- mobile analytics collectors
