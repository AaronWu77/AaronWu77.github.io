# Chapter 27 Security Engineering

## Why Security Engineering?
安全不是附加项，而是系统可信的前提。

- security supports integrity, availability, reliability, and safety
- assets must be protected from attack
- security must be designed in from the beginning

## Analyzing Security Requirements
安全需求先要看资产、威胁和控制。

- exposure：资产损失的价值
- threat analysis：识别威胁条件
- controls：用来避免或减轻攻击后果

## Online Security Threats
在线环境让威胁来源更多、更复杂。

- social media
- mobile applications
- cloud computing
- Internet of Things

## Security Engineering Analysis
安全分析要从需求、模型和测试三个层次展开。

- abuser stories
- threat modeling
- security modeling
- state models for secure transitions
- security metrics and correctness checks

## Security Assurance
安全保证要给出“为什么可信”的证据链。

- security claims
- arguments
- evidence
- reviews, proofs, tests, audits

## Security Risk Analysis
风险分析要先把威胁建模出来。

- identify assets
- build architecture overview
- decompose application
- identify threats
- rate and document threats

## System Trustworthiness
trustworthiness 关注系统和利益相关者之间的可信程度。

- trust is the level of confidence
- verification must be objective and traceable
- evidence must be convincing to stakeholders
