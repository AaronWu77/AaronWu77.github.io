# Chapter 15 User Interface Design

## Why UI Design Matters
界面设计决定用户能不能学会、会不会用、愿不愿意继续用。

- easy to learn
- easy to use
- easy to understand
- typical design errors: inconsistent, hard to remember, no help, poor response

## Golden Rules
UI 设计的基本目标很直接。

- place the user in control
- reduce the user’s memory load
- make the interface consistent

## Place the User in Control
用户应该能掌控交互，而不是被界面“绑住”。

- interaction should be flexible
- actions should be interruptible and undoable
- hide technical internals from casual users
- support direct interaction with on-screen objects

## Reduce the User’s Memory Load
减少短期记忆负担，才能降低使用门槛。

- meaningful defaults
- intuitive shortcuts
- progressive disclosure
- visual layout should match real-world metaphor

## Make the Interface Consistent
一致性让用户靠经验操作，而不是重新学习。

- same task, same location
- same action, same behavior
- avoid unnecessary changes to proven interaction models

## User Interface Design Models
常见的四种模型要保持一致。

- user model
- design model
- mental model
- implementation model

## Interface Analysis
界面分析要先理解四件事。

- who the users are
- what tasks they perform
- what content is presented
- what environment they work in

## User Analysis and Task Analysis
分析用户和任务，才能设计对的界面。

- 用户画像：教育背景、经验、语言、错误后果
- 任务分析：工作流、子任务、对象、顺序、层次
- 需要把 use-cases、task elaboration、workflow analysis 串起来

## Analysis of Display Content
内容放什么、怎么放、放在哪，都影响易用性。

- content should be clearly identified
- large reports should be partitioned
- error messages should be clear
- color and layout should help understanding

## Interface Design Steps
界面设计是从分析模型逐步收敛到具体屏幕。

1. review analysis model
2. sketch layout
3. map user objectives to actions
4. define tasks per action
5. storyboard screens
6. refine with aesthetic design

## Design Issues
设计时要持续关注细节。

- response time
- help facilities
- error handling
- labeling
- accessibility
- internationalization

## Web and Mobile Interface Design
Web / Mobile 的界面要特别注意导航、屏幕大小和多媒体内容。

- 让用户知道“我在哪、能干什么、去哪”
- 提供清晰的导航地图
- 小屏幕环境下要更克制

## Effective Interfaces
有效界面应该可见、可控、可恢复。

- visually apparent
- forgiving
- save work continuously
- support undo
- require minimal user input

## Interface Design Principles
WebApp 界面设计常用的原则包括。

- anticipation
- communication
- consistency
- controlled autonomy
- efficiency
- focus
- Fitt’s Law
- latency reduction
- learnability
- visible navigation

## Workflow and Aesthetic Design
布局要服务内容，不要反过来。

- 自上而下、从左到右组织信息
- 保留 white space
- 不要让滚动条破坏可读性
- 按分辨率和窗口大小设计

## Design Evaluation Cycle
界面设计要不断评估和修正。

- 原型评估
- 可用性测试
- 根据反馈迭代
