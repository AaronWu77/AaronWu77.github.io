# 数字逻辑设计课程引入

## 课程评分标准

**Final Score**: Classroom Performance 30% + Project 10% + Final Examination 40% + Experiment 20%

**Classroom Test**: 
- Nonscheduled, without notification
- From textbook and home assignments

**Project**: 
- Source code, source project and technical report should be submitted
- Technical report: including analysis and design process, debugging process, simulation sequential diagram
- Deadline: One week before examination

**Experiment**:
1. 常用数字仪器的使用
2. 二极管与三极管开关电路
3. 集成逻辑门电路的功能及参数测试
4. EDA实验平台与实验环境运用
5. 变量译码器设计与应用
6. 7段数码管显示译码器设计与应用
7. 多路选择器设计及应用（实验调试测试环境搭建）
8. 全加器的设计实现
9. 加法器和ALU基本原理与设计
10. 锁存器与触发器基本原理
11. 同步时序电路设计
12. 寄存器推及寄存器传输设计
13. 计数器/定时器设计与应用
14. 移位寄存器设计与应用
