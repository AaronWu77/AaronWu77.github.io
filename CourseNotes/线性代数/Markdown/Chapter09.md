# 第9章 实向量空间上的算子

## 9.A 复化与实空间结构
实向量空间上的算子常常要借助复数来理解。

- 先把实空间扩展到复空间，很多结构更容易分析
- 复空间中的结论再返回实空间
- 这是研究 real operator 的常见思路

## 9.B 实空间中的标准形
实空间并不总能直接得到复空间那样的对角化。

- 有些算子没有实特征值
- 这时需要用二维不变子空间来描述结构
- 实空间上的标准形通常比复空间更复杂

## 9.C 正交与旋转结构
实空间上的 orthogonal operator 体现的是几何保持性。

- 保持长度和角度
- 可以理解为旋转、反射或它们的组合
- 与复空间中的 unitary operator 类似

## 9.D 自伴与谱分解
实空间里的 self-adjoint operator 也有漂亮性质。

- 具有实特征值
- 可以用正交基对角化
- 是最重要的可分析算子之一

## 9.E 本章作用
第9章强调的是：实空间虽然不如复空间“完全”，但仍然可以通过适当分解得到清晰结构。

- 用复化辅助分析
- 用二维块处理复特征值问题
- 继续保持几何解释
