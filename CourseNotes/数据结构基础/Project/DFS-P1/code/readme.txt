--------------
1. project1.c
   - 说明：主要的 C 语言程序，包含二分查找（迭代和递归）以及顺序查找（迭代和递归）的实现。它还包含一个用于测量执行时间的性能测试工具。
   - 主要特点：
     - 包含解释特定逻辑的内部代码注释。
     - 专门针对最坏情况进行基准测试。

2. plot_results.py
   - 说明：一个专用的 Python 脚本，用于解析 `project1.c` 生成的性能数据并绘制可视化图表（例如，使用 matplotlib）。它有助于直观地比较 O(log N) 和 O(N) 复杂度的运行时间曲线。

编译和执行
-------------------------
要编译和执行 C 程序，请运行：
    gcc project1.c -o project1
    ./project1

注意：生成数据后，请确保运行 Python 脚本以查看绘制的图表结果。
