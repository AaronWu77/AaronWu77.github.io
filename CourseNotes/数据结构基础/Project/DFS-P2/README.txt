DFS-P2: Normal-2 A+B with Binary Search Trees

【文件说明】
- main.c: 核心程序源代码，包含详细的中文注释。
- project2.md: 实验报告。
- benchmark.c: 针对核心算法的性能基准测试程序。
- run_all_cases.sh: 自动化边界条件与异常用例测试脚本。


【运行方法】
1. 编译并运行主程序:
   gcc main.c -o solution
   ./solution

2. 运行自动化边界测试:
   chmod +x run_all_cases.sh
   ./run_all_cases.sh

3. 运行性能跑分测试:
   gcc benchmark.c -o benchmark
   ./benchmark
