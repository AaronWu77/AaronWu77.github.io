**1-4** For the following piece of code

```C
if ( A > B ){
    for ( i=0; i<N*2; i++ )
        for ( j=N*N; j>i;j-- )
            C += A;
}
else{
    for ( i=0; i<N*N/100; i++ )
        for ( j=N; j>i; j-- )
            for ( k=0; k<N*3; k++ )
                C += B;
}
```
the lowest upper bound of the time complexity is $O(N^3)$

**Answer** F
