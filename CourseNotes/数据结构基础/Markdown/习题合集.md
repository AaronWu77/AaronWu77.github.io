# 期中难题汇总

**1-2** The Fibonacci number sequence {$F_N$} is defined as: $F_0=0,\ F_1=1\ F_N=F_{N-1}+F_{N-2},\ N=2,3,...$ The time complexity of the function which calculates $F_N$ recursively is $\Theta(N!)$

**1-3** $O(N^2)$ is the same as $O(1+2+3+\cdots+N)$.

**1-4** For the following piece of code

```C
if ( A > B ){
    for ( i=0; i<N*2; i++ )
        for ( j=N*N; j>i;j-- )
            C += A;
}
else{
    for ( i=0; i<N*N/100; i++ )
        for ( j=N; j>i; j-- )
            for ( k=0; k<N*3; k++ )
                C += B;
}
```
the lowest upper bound of the time complexity is $O(N^3)$

**1-5** $(log n)^{100}$ is $O(n^{0.01})$
