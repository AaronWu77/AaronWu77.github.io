## 一、课程简介

### 1.1 课程定位

《计算机体系结构》是计算机专业的一门核心专业课，从**计算机系统**的整体角度，介绍现代处理器和存储系统的**设计原理与方法**。

本课程与"计算机组成原理"的区别在于：

- **计算机组成原理**：关注单个部件的实现（ALU、寄存器堆、控制器……）
- **计算机体系结构**：关注整个系统的**性能优化**和**设计权衡**，站在更高的抽象层次上思考"如何让计算机跑得更快、更省电"

### 1.2 理论课内容

课程理论部分分为五大模块：

| 模块 | 核心主题 |
|------|----------|
| 基础 | 体系结构基本概念、设计生命周期、量化设计原理、性能评价 |
| 存储体系 | Cache性能提升、存储器技术、虚拟存储器与虚拟机 |
| 指令级并行（ILP） | 转移预测、动态调度、猜测执行、多发射处理器 |
| 数据级并行（DLP） | 向量处理器、SIMD、GPU |
| 线程级并行（TLP） | 多处理器结构、Cache一致性、同步原语 |

### 1.3 实验课内容

实验在 **Vivado** 工具下使用 **Verilog** 语言完成硬件设计，并在 FPGA 板上验证：

1. 实现支持 RV32I、forwarding（数据前递）和 predict-not-taken（预测不跳转）的**五级流水线 CPU**
2. 实现**精确中断**机制
3. 实现**2路组关联 Cache** 并应用于指令流水线
4. 扩展流水线以支持**多周期复杂操作**（如浮点运算）
5. 实现基于 **Scoreboard 算法**的动态调度流水线 CPU

### 1.4 课程体系背景

浙大的课程体系采用"渐进式"的系统能力培养思路：

```
数字逻辑 → 计算机组成(CPU) → 体系结构(流水CPU) → 简易计算机系统
                                ↓
                         高级数字系统 → SOC设计 → 多核系统
```

从底层到顶层：**数字电路 → RTL设计 → 微架构 → 体系结构 → 操作系统/编译器 → 应用**。体系结构课程处于硬件系统设计的中上层，承上启下。

## 二、什么是计算机体系结构（Computer Architecture）

### 2.1 定义与层次

计算机体系结构并不是一个单一的概念，而是连接**硬件实现**与**软件需求**的桥梁。常见的理解层次如下：

```
应用软件 (Application)
操作系统 (Operating System)
编译器 (Compiler)
─────────────────────────────
指令集架构 ISA (Instruction Set Architecture)   ← 软硬件接口
─────────────────────────────
微架构 / 数据通路与控制 (Datapath & Control)
固件 (Firmware)
数字设计 (Digital Design)
电路设计 (Circuit Design)
物理版图 (Layout)
```

**ISA（Instruction Set Architecture，指令集架构）** 是软硬件的分界线：  
- 软件开发者看到的是 ISA（寄存器、指令格式、寻址方式……）  
- 硬件设计者根据 ISA 设计具体的微架构实现  

### 2.2 体系结构 vs. 组织 vs. 实现

| 概念 | 关注点 | 举例 |
|------|--------|------|
| **指令集架构（ISA）** | 程序员可见的接口 | RISC-V、x86、ARM |
| **计算机组织（Computer Organization）** | 如何实现ISA的高层设计 | 流水线级数、Cache结构 |
| **计算机实现（Computer Implementation）** | 具体的物理实现 | 晶体管尺寸、时钟频率、芯片面积 |
| **计算机体系结构** | 三者综合，强调**设计权衡与量化分析** | 性能/功耗/成本的平衡 |

## 三、当前面临的核心挑战

### 3.1 单处理器性能提升的困境

早期计算机性能提升主要依靠：
- 晶体管数量翻倍（摩尔定律）
- 工作频率持续提高（2.0~3.5 GHz）
- 供电电压不断降低（0.9~1.2 V）

但这条路已经走到瓶颈：
- **功耗墙（Power Wall）**：频率提高导致功耗剧增，芯片无法散热
- **存储墙（Memory Wall）**：CPU速度提升远快于内存带宽
- **ILP墙（ILP Wall）**：单线程的指令级并行开发潜力接近极限

因此，现代体系结构研究的重心转向**并行计算**和**专用架构（DSA）**。

### 3.2 新兴挑战

| 挑战 | 说明 |
|------|------|
| 数据密集型应用 | 大数据、AI训练需要极高的内存带宽 |
| 功耗/能效约束 | 数据中心和移动设备都对能效有严格要求 |
| 设计复杂性 | 现代芯片动辄几十亿晶体管，验证和调试极其困难 |
| 技术缩放困难 | 3nm/2nm工艺接近物理极限，良率和成本剧增 |
| 内存瓶颈 | 内存延迟和带宽成为性能提升的主要障碍 |
| 可靠性问题 | 纳米级器件更容易出现软错误（soft error） |
| 可编程性 | 多核/异构架构的编程模型复杂，难以充分利用硬件 |
| 安全与隐私 | 微架构优化带来了新的安全漏洞（见 §五） |

### 3.3 新型计算装置

除了传统硅基芯片，研究者还在探索：
- **光子计算机（Light Computer）**：用光信号代替电信号，速度极高
- **分子计算机（Molecule Computer）**：利用分子的化学反应进行计算
- **DNA计算机**：利用DNA链的碱基配对实现大规模并行计算

这些都是长期研究方向，目前还未进入实用阶段。

## 四、超级计算机发展简史

超级计算机（Supercomputer）性能通常以 **FLOPS（Floating Point Operations Per Second，每秒浮点运算次数）** 来衡量。

### 4.1 中国超算发展里程碑

## 五、前沿技术展望

### 5.1 开源指令集架构 RISC-V

**RISC-V** 是一套完全开放的指令集架构（ISA），基于精简指令集（RISC）设计原则：

- **完全开源**：学术界和工业界均可免费使用，无需授权费
- **模块化设计**：
  - 基础整数指令集：RV32I（32位）、RV64I（64位）
  - 可选扩展模块：M（乘除法）、A（原子操作）、F/D（浮点）、V（向量）……
- **典型开源实现**：Rocket（UC Berkeley）、蜂鸟E203（芯来科技）、PULPino
- **商业实现**：SiFive 等公司提供商业级 RISC-V 处理器

RISC-V 已经被本课程的实验采用（RV32I），也是当前最受关注的开源芯片生态之一。

### 5.2 安全漏洞：Spectre 与 Meltdown

现代处理器为了提高性能，使用了大量复杂的微架构技术，这些技术带来了严重的安全漏洞：

**Meltdown（熔断）**：
- 原因：乱序执行（Out-of-Order Execution）
- 攻击者可以读取操作系统内核的私有内存数据
- 机制：CPU乱序执行后会检查权限，但执行结果已经进入 Cache，攻击者通过 Cache 侧信道读取数据

**Spectre（幽灵）**：
- 原因：分支预测（Branch Prediction）+ 猜测执行（Speculative Execution）
- 攻击者可以诱导受害进程泄露其私有数据
- 更难以从根本上修复，影响范围更广

**Intel ME（Management Engine）**：
- 内嵌在 Intel 芯片中的独立小处理器，对用户完全不透明
- 存在被远程攻击的风险

### 5.3 安全防护机制

**指针认证（Pointer Authentication）**：
- 64位地址空间并未使用全部64位，高位可以存放指针的"签名"（密码学摘要）
- 新增指令对指针进行签名/验证，防止指针被篡改（对抗 ROP/JOP 攻击）

**可信执行环境（Enclave）—— Intel SGX**：
- 在不可信的平台（云主机/受感染的OS）上创建可信的执行区域
- 信任根（Root of Trust）位于CPU本身
- 只要信任CPU厂商，就可以相信 Enclave 内的代码和数据是安全的

### 5.4 领域专用架构（Domain Specific Architecture，DSA）

通用处理器（CPU）在处理特定任务时效率低下，无论是性能还是能效都有明显短板。DSA 针对特定应用领域进行专门优化：

| 产品 | 厂商 | 应用场景 |
|------|------|----------|
| TPU（Tensor Processing Unit） | Google | 数据中心AI推理与训练 |
| Pixel vCore | Google | 手机端AI应用（Pixel手机） |
| 寒武纪 NPU | 寒武纪科技 | 移动端/数据中心AI加速 |

DSA 的核心思路：**牺牲通用性，换取特定领域的极致性能与能效**。这是当前体系结构研究最热门的方向之一。

## 总结

本章作为课程引入，建立了以下核心认知：

1. **体系结构 = ISA + 微架构 + 实现的综合设计权衡**，与组成原理的区别在于更强调系统级性能分析。

2. **三大并行维度**是现代体系结构的核心：
   - ILP（指令级并行）：流水线、乱序执行、分支预测
   - DLP（数据级并行）：向量、SIMD、GPU
   - TLP（线程级并行）：多核、多处理器

3. **性能提升的瓶颈**：功耗墙、存储墙、ILP墙。解决方案不再是"提高频率"，而是**并行化**与**专用化**。

4. **安全是现代体系结构的重要约束**：Spectre/Meltdown 说明微架构优化可能引入安全漏洞，设计时必须考虑安全性。

5. **RISC-V 和 DSA** 是当前最活跃的研究和工程方向，本课程实验即采用 RISC-V ISA。
