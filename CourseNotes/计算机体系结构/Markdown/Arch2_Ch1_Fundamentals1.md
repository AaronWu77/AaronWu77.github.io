## 一、计算机发展历史概述

### 1.1 六十年间的巨变

过去六十年，计算机经历了令人难以置信的性能飞跃：

> 今天售价 500 美元的计算机，其性能、内存和磁盘容量，相当于 1985 年价值 **100 万美元**的计算机。

性能每年约提升 **25%**（存储约 20%/年）。驱动这一变化有两大原因：

1. **技术进步**：集成电路（IC）、存储器（RAM/磁盘）、外设技术的持续发展
2. **计算机设计创新**：设计思想经历了从简单→复杂→极简→复杂的螺旋式发展

### 1.2 微处理器的四个十年

| 时代 | 主题 | 代表技术 |
|------|------|----------|
| 1970s | 微处理器 | 可编程控制器、单芯片微处理器、PC |
| 1980s | 量化体系结构 | 指令流水线、快速Cache、编译器优化、工作站 |
| 1990s | 指令级并行（ILP） | 超标量处理器、猜测执行微架构、激进代码调度 |
| 2000s+ | 线程级/数据级并行 | 多核、GPU、向量处理器 |

**关键转变**：RISC 架构的出现让计算机设计开始同时强调"架构创新"和"高效利用工艺进步"。  
然而，由于**功耗限制**，单核 ILP 的潜力已接近极限，性能提升的范式从"隐式并行（编译器+硬件）"转向"显式并行（程序员+架构工程师）"。

## 二、Flynn 分类法：计算机体系结构分类

**Flynn 分类法（Flynn's Taxonomy）** 由 Michael J. Flynn 提出（1966年），根据**指令流**和**数据流**的数量对计算机架构进行分类。

| 类型 | 全称 | 指令流 | 数据流 | 特点 |
|------|------|--------|--------|------|
| **SISD** | Single Instruction Single Data | 1 | 1 | 传统串行计算机 |
| **SIMD** | Single Instruction Multiple Data | 1 | 多 | 向量/阵列处理器、GPU |
| **MISD** | Multiple Instruction Single Data | 多 | 1 | 极少实现，几乎无实际产品 |
| **MIMD** | Multiple Instruction Multiple Data | 多 | 多 | 现代多核/多处理器，最主流 |

### 2.1 SISD — 传统串行计算机

- 每个时钟周期执行一条指令，处理一个数据
- 执行是**确定性**的（给定输入，结果唯一）
- 代表：大多数早期 PC、单 CPU 工作站

### 2.2 SIMD — 单指令多数据

- **所有处理单元同时执行同一条指令**，但各自操作不同的数据元素
- 硬件特点：指令分发器、高带宽内部网络、大量小型处理单元
- 最适合**高度规律性**的问题，如：图像处理、矩阵运算
- 两种形式：
  - **处理器阵列（Processor Arrays）**：Connection Machine CM-2, Maspar MP-1/MP-2
  - **向量流水线（Vector Pipelines）**：Cray C90、NEC SX-2
- **现代应用**：CPU 中的 SSE/AVX 指令、GPU 的 CUDA Core

### 2.3 MISD — 多指令单数据（几乎无实现）

- 多条指令流并行处理同一数据流
- 典型应用场景（理论上）：同时运行多个密码算法破解同一消息
- 历史上极少有真实实现（CMU 的 C.mmp 实验机，1971年）

### 2.4 MIMD — 多指令多数据（当前主流）

- 每个处理器独立执行不同的指令流，处理不同的数据流
- 执行可以是同步或异步的，可以是确定性或非确定性的
- 代表：**现代多核处理器**、集群超算、SMP 服务器
- 这是目前**最常见**的并行计算架构

## 三、计算机市场分类

### 3.1 四大计算市场

**① 台式机（Desktop Computing）**
- **最大市场**（按美元计）
- 核心需求：**优化性价比（Price-Performance）**
- 当前挑战：以 Web 为中心的交互式应用，性能评价标准多样

**② 服务器（Servers）**
- 随着文件服务和计算服务需求增长而兴起
- 核心特点：
  - **可依赖性（Dependability）**：不能宕机，7×24 小时稳定运行
  - **可扩展性（Scalability）**：能随需求增加计算/存储资源
  - **高吞吐量（Throughput）**：关注单位时间处理的任务数，而非单任务延迟

**③ 嵌入式计算机 / 物联网（Embedded/IoT）**
- 覆盖范围极广：8位/16位/32位/64位处理器，功耗从 0.1mW 到 2000W
- 特点：
  - **实时性能（Real-Time Performance）**：分硬实时（Hard RT）和软实时（Soft RT）
  - **资源约束严格**：有限内存、最小功耗
  - 常配备专用硬件：DSP、应用专用电路
- 典型 OS：Linux Embedded、FreeRTOS、VxWorks

**④ 个人移动设备（Personal Mobile Device, PMD）**
- 代表：智能手机、平板
- 特点：
  - Web 和媒体应用为主
  - 支持第三方 APP（这是与嵌入式的**关键区别**）
  - **能效至上**：电池供电，无风扇，严格的散热约束
  - 实时性能要求（如游戏、AR）

### 3.2 市场演变

微处理器的普及使所有计算市场的底层实现趋于一致：
- 小型机 → 基于微处理器的服务器
- 主机 → 多处理器（微处理器集群）
- 超级计算机 → 大规模多处理器系统

## 四、计算机体系结构的定义与任务

### 4.1 原始定义（Amdahl, Blaaw, Brooks, 1964）

> "计算机体系结构是程序员所看到的计算机系统的属性，即概念结构和功能行为，有别于数据流与控制的组织、逻辑设计和物理实现。"

### 4.2 指令集架构（ISA）

**ISA（Instruction Set Architecture）** 是体系结构的核心，是**软件与硬件之间的接口契约**。

ISA 的两个作用：
1. ~~复用固定硬件资源（早期目的，现已不再重要）~~
2. **开发者与硬件之间的接口**，以及芯片代际间的兼容性保证

**良好 ISA 设计的特征**：
- 经历多代实现仍保持兼容（**可移植性、可兼容性**）
- 适用于多种不同场景（**通用性**）
- 为上层软件提供便利的功能
- 允许下层高效实现

### 4.3 ISA 的七个维度

| 维度 | 说明 |
|------|------|
| **类别（Class）** | 寄存器-寄存器、寄存器-内存、内存-内存 |
| **内存寻址（Memory addressing）** | 字节寻址方式，大端/小端 |
| **寻址模式（Addressing modes）** | 立即数、直接、间接、相对、基址+偏移…… |
| **操作数类型与大小** | 整数/浮点、8/16/32/64位 |
| **操作（Operations）** | 整数运算、逻辑运算、浮点运算、控制流 |
| **控制流指令** | 跳转、条件分支、过程调用/返回 |
| **编码（Encoding）** | 定长/变长，操作码位置 |

### 4.4 计算机架构课程的演进

| 时代 | 研究重心 |
|------|----------|
| 1950s~60s | 计算机算术 |
| 1970s~80s | 指令集设计，尤其是对编译器友好的 ISA |
| 1990s | CPU/内存/I-O/多处理器/网络综合设计 |
| 2010s | 多核、自适应系统、功耗感知设计 |
| 2020s | 异构加速器（GPU/FPGA/TPU/NPU）、安全设计 |

### 4.5 完整定义

> "计算机体系结构是选择和互连硬件组件，以创建满足功能、性能和成本目标的计算机的科学与艺术。"

涵盖三层：
1. **指令集设计（ISA Design）**
2. **组织结构（Organization）**：内存系统、总线架构、CPU内部高层设计
3. **硬件（Hardware）**：详细逻辑设计、封装、散热、电源

### 4.6 计算机设计的任务

**第一步：定义用户需求**

- **功能性需求**：
  - 应用领域（科学计算、商业、实时……）
  - 软件兼容性级别
  - OS 需求
  - 遵循的标准
- **非功能性需求**：
  - 性价比（Price/Performance）
  - 可用性（Availability）、可扩展性（Scalability）、吞吐量（Throughput）
  - 功耗（Power）、尺寸（Size）、温度（Temperature）

**第二步：量化分析与设计**

应用行为直接驱动处理器设计：
- 科学计算（气象预报、地震分析）→ 强调高精度浮点运算
- 商业（数据库、数据挖掘）→ 强调内存带宽和 I/O
- 通用应用（Office）→ 强调整数性能和分支预测

**经典案例**：
- HP 服务器：针对事务处理优化了 1.5 MB 的 Cache
- Alpha 处理器：超快的浮点单元，针对科学计算
- StrongARM：嵌入式优化
- Intel MMX：多媒体扩展
- Sony Emotion Engine：图形渲染

**应用性能的现实**（以 CPU 每年翻倍性能为例）：

| 年份 | CPU 性能提升 | 程序实际加速（50%CPU+50%I/O）|
|------|-------------|------|
| 1996→1997 | ×2 | ×1.33 |
| 1997→1998 | ×2 | ×1.20 |
| 1998→1999 | ×2 | ×1.11 |

→ **结论**：CPU 性能翻倍，并不等于实际程序翻倍，因为 **I/O 瓶颈** 无法被 CPU 加速消除。这正是后续章节讨论存储层次、I/O 系统的动机。

### 4.7 计算机设计生命周期

```
用户需求 + 技术趋势 + 基准测试 + 量化原理
         ↓
    评估现有系统瓶颈
         ↓
    仿真新设计与组织结构
         ↓
    实现下一代系统
```

## 五、技术趋势

### 5.1 摩尔定律（Moore's Law）

1965年，Intel 联合创始人 Gordon Moore 预测：  
> "集成电路上的晶体管数量每年翻倍（后来修正为每两年翻倍）。"

摩尔定律成为半导体行业的指导原则，推动了几十年的计算机性能革命。

### 5.2 各技术的增长趋势

| 技术 | 指标 | 增长速率 |
|------|------|----------|
| IC 逻辑 | 晶体管密度 | 每年 +35%（每4年 ×4） |
| IC 逻辑 | 芯片面积 | 每年 +10~20% |
| IC 逻辑 | 每芯片晶体管数 | 每年 +40~55% |
| DRAM | 容量 | 每年 +40%（每2年 ×2） |
| DRAM | 速度 | 每年 +10% |
| 磁盘 | 密度（1996前） | 每年 +30% |
| 磁盘 | 密度（1990~1996） | 每年 +60% |
| 磁盘 | 密度（1996~2004） | 每年 +100% |
| 磁盘 | 密度（2004后） | 每年 +30% |
| 网络 | 带宽 | 10M→100M→1G→10G→100G（约10年一代） |

> 💡 **经验法则**：成本下降速率 ≈ 密度增长速率  
> 💡 **带宽 vs 延迟**：带宽增长速率 ≈ 延迟改善的平方（带宽增长比延迟快得多）

**重要设计原则**：设计者通常面向**下一代技术**进行设计，而不是当前技术——因为芯片从设计到量产需要 2~3 年。

### 5.3 IC 特征尺寸（Feature Size）发展

| 年份 | 特征尺寸 |
|------|----------|
| 1971 | 10 微米（10μm） |
| 2001 | 0.18 微米（180nm） |
| 2006 | 65nm |
| 之后 | 40nm → 28nm → 14nm → 7nm → 5nm → 3nm → 2nm |

> 💡 **经验法则**：晶体管性能与特征尺寸成**线性反比**，特征尺寸越小，晶体管越快。

**技术挑战**：
- 连线（Wire）的信号延迟随着电阻×电容（RC）乘积的增加而增加
- 特征尺寸缩小时，连线延迟反而可能增加（相对晶体管延迟而言）
- 这是设计中的主要限制因素之一

## 六、集成电路的功耗趋势

这是**当前体系结构设计中最关键的约束**之一。

### 6.1 功耗问题的严重性

| 处理器 | 功耗 |
|--------|------|
| 第一代微处理器（1971） | 1~10 瓦 |
| 2GHz Pentium 4 | 135 瓦 |
| 3.6GHz Pentium 4 Prescott | 225 瓦以上 |

随着频率提高，功耗急剧上升，带来了**散热**、**供电分配**和**热点（Hot Spot）** 三大挑战。

### 6.2 两类功耗

#### 动态功耗（Dynamic Power）

动态功耗来自晶体管**开关（switching）**时对电容的充放电：

$$P_{dynamic} = \frac{1}{2} \times C_L \times V^2 \times f_{switch}$$

$$E_{dynamic} = C_L \times V^2$$

其中：
- $C_L$：电容负载（与晶体管尺寸和连线有关）
- $V$：供电电压
- $f_{switch}$：开关频率

**关键洞察**：
- 功耗与电压的**平方**成正比，降低电压是降低功耗最有效的手段
- 功耗与频率成**线性**关系

#### 静态功耗（Static Power）

静态功耗来自晶体管**关断时的漏电流（Leakage Current）**：

$$P_{static} = I_{static} \times V$$

随着特征尺寸缩小，漏电流**显著增加**，静态功耗已成为不可忽视的问题。

### 6.3 电压缩减的经验法则

**电压降低 10%** 的效果：
- 频率降低约 **10%**（$f_{max}$ 与 $V$ 近似成正比）
- 动态功耗降低约 **30%**（$P \propto V^2 \times f$，$V$ 降10%且$f$降10%）
- 性能降低**不到 10%**（频率降了但 IPC 不受影响）

$$\text{功耗节省} > \text{性能损失}$$

### 6.4 多核的功耗优势

以双核处理器为例（降压运行）：

| 指标 | 单核 | 双核（各降压15%） |
|------|------|---------|
| 面积 | 1 | 2 |
| 电压 | 1 | 0.85 |
| 频率 | 1 | 0.85 |
| **功耗** | **1** | **≈1** |
| **性能** | **1** | **≈1.8** |

**结论**：双核降压运行，功耗与单核相当，但性能提升 80%！这正是多核架构的核心动机。

**更普遍的规律**：
- 功耗 ≈ 面积（$P \propto \text{Area}$）
- 单线程性能 ≈ 面积的平方根（$\text{Perf}_{single} \propto \text{Area}^{0.5}$）
- 因此，同等功耗下，多个小核比一个大核更**能效高**

**PPA（性能×功耗×面积）演变**（17年间）：

| 处理器 | 年份 | 工艺 | 晶体管数 | SPECint2000 |
|--------|------|------|----------|-------------|
| 386 | 1986 | 1.5μm @ 16MHz | 27.5万 | ~1.2 |
| Pentium 4 | 2003 | 0.13μm @ 3.2GHz | 5500万 | 1249 |

- 性能提升 **200倍**，但面积增长 **11倍**
- 性能/面积 = 200/11 ≈ **18倍**，而性能 ∝ 面积⁰·⁵预测应有 √11 ≈ 3.3倍……
- 说明频率提升贡献了大量性能，但**功耗效率已显著下降**

## 七、总结

本章（上半部分）建立了以下核心认知：

1. **Flynn 分类法**：SISD/SIMD/MISD/MIMD，现代计算机主要是 MIMD（多核）和 SIMD（向量/GPU）。

2. **四大计算市场**各有不同设计目标：
   - 台式机：性价比
   - 服务器：可靠性 + 可扩展性 + 吞吐量
   - 嵌入式：实时性 + 低功耗 + 资源约束
   - PMD：能效 + 实时性 + 低成本

3. **ISA 是软硬件接口**，良好的 ISA 需要兼顾可移植性、通用性和高效实现。

4. **摩尔定律驱动**技术发展：晶体管数每年 +40~55%，但延迟改善慢于带宽改善。

5. **功耗是当前主要设计约束**：
   - 动态功耗 ∝ $V^2 \times f$，降压是最有效手段
   - 多核降压运行 = 相同功耗，更高性能
   - 这是现代多核架构的根本动机
